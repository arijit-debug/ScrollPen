# ScrollPen desktop app

React Native for Windows 0.84 (Fabric, C++ host). Windows only.

```powershell
npm install
npm run windows          # debug build + launch (Metro starts automatically)
npm run windows:release  # release build, JS bundled into the app
npm test                 # Jest (react-native-windows preset)
```

The Visual Studio solution is `windows/ScrollPen.sln`. See the root README for machine setup.
